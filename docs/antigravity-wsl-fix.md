# 🔧 Solución Antigravity WSL Launcher

## Problema
Antigravity tiene 3 bugs conocidos al lanzarse desde WSL:
1. **`agy` no está en PATH** → Comando no encontrado
2. **Extension ID incorrecto** → `ms-vscode-remote.remote-wsl` en lugar de `google.antigravity-remote-wsl`
3. **Scripts auxiliares faltantes** → `wslCode.sh`, `wslDownload.sh` no incluidos en la instalación

## Solución Implementada (V5)

### Estrategia
En lugar de intentar ejecutar `Antigravity.exe` directamente desde WSL (lo cual falla por los problemas de interpolación de variables), creamos un **wrapper script persistente** en WSL que:

1. Se crea una sola vez en `~/.local/bin/agy-launcher`
2. Persiste entre sesiones
3. Llama al script `antigravity` de Windows (que ya tiene toda la lógica de Electron)
4. Convierte paths WSL → Windows automáticamente

### Código C# para MainWindow.xaml.cs

```csharp
// Reemplazar líneas 396-425 con esto:

// V5: Crear wrapper script persistente en WSL
var localAppData = Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData);
string winUser = Environment.UserName;
var agyBinPath = System.IO.Path.Combine(localAppData, "Programs", "Antigravity", "bin", "antigravity").Replace("\\", "/");

// Script que crea el wrapper en ~/.local/bin/agy-launcher (persistente)
string setupScript = $@"
#!/bin/bash
echo '🔧 Antigravity WSL Launcher Setup V5...'

# 1. Crear directorio si no existe
mkdir -p ~/.local/bin

# 2. Crear wrapper script
cat > ~/.local/bin/agy-launcher << 'WRAPPER_EOF'
#!/bin/bash
# Antigravity WSL Wrapper - Auto-generated by Chapi Assistant

AGY_WIN=""{agyBinPath}""
TARGET_DIR=""${{1:-.}}""

# Convertir path WSL -> Windows si es necesario
if [[ ""$TARGET_DIR"" == /* ]]; then
    TARGET_DIR=$(wslpath -w ""$TARGET_DIR"" 2>/dev/null || echo ""$TARGET_DIR"")
fi

# Ejecutar Antigravity
""$AGY_WIN"" ""$TARGET_DIR""
WRAPPER_EOF

# 3. Dar permisos
chmod +x ~/.local/bin/agy-launcher

# 4. Verificar PATH
if [[ ! ""$PATH"" =~ ""$HOME/.local/bin"" ]]; then
    echo ""export PATH=\$HOME/.local/bin:\$PATH"" >> ~/.bashrc
    echo '⚠️  Added ~/.local/bin to PATH in .bashrc'
fi

echo '✅ Wrapper created: ~/.local/bin/agy-launcher'
echo '🚀 Launching...'

# 5. Ejecutar
~/.local/bin/agy-launcher .
";

var scriptB64 = Convert.ToBase64String(System.Text.Encoding.UTF8.GetBytes(setupScript));

Process.Start(new ProcessStartInfo 
{ 
    FileName = "cmd.exe",               
    Arguments = $"/c start \"Antigravity WSL\" wsl -d {distro} --cd \"{linuxPath}\" bash -c \"echo {scriptB64} | base64 -d | bash\"", 
    UseShellExecute = true 
});
```

## Ventajas

✅ **No modifica la instalación de Antigravity** → Sobrevive a actualizaciones  
✅ **Wrapper persistente** → Solo se crea una vez  
✅ **Conversión automática de paths** → WSL ↔ Windows  
✅ **Base64 encoding** → Elimina problemas de escape de comillas  
✅ **Usa el launcher oficial** → Aprovecha toda la lógica de Electron ya implementada

## Uso

Después de la primera ejecución desde Chapi Assistant:

```bash
# En WSL, desde cualquier carpeta:
agy-launcher .

# O simplemente (si está en PATH):
agy-launcher ~/mi-proyecto
```

## Notas

- El wrapper se crea en `~/.local/bin/agy-launcher`
- Si `~/.local/bin` no está en PATH, se agrega automáticamente a `.bashrc`
- Reiniciar el shell o ejecutar `source ~/.bashrc` para que tome efecto
